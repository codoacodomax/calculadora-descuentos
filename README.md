# Calculadora de descuentos

Programa desarrollado en Python que permite calcular el precio final de un producto aplicando un porcentaje de descuento.

## Funcionalidad

El programa solicita al usuario:

- El monto al que se le aplicará el descuento.
- El porcentaje de descuento.

Luego calcula y muestra el precio final.

## Tecnologías utilizadas

- Python
- Visual Studio Code
- Git
- GitHub

## Conceptos de Python utilizados

- Variables
- Entrada de datos con `input()`
- Conversión de tipos con `float()`
- Funciones
- Operaciones matemáticas
- Salida de datos con `print()`

## Ejemplo de uso

Ingrese solamente el monto al cual se le aplicará el descuento: 10000
Ingrese solamente el numero (sin el %) correspondiente al descuento: 20

Precio final: 8000
